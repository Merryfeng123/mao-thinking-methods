# mao-thinking-methods

> 来自《毛泽东选集》（毛泽东，1937–1949）的**思维方法**底座。
> 把86 万字编译成 **160 篇逐段拆解 + 40 个方法论模式 + 一页速查卡**。

本技能由 `book-in-skill` 从《毛泽东选集》1–4 卷（求是网官方全文，qstheory.cn）编译而成。

---

## 这不是书摘

书摘回答「他说了什么」，本技能回答「**他怎么想问题**」。

| 提炼的思维工具 | 原话依据 |
|---|---|
| **抓主要矛盾** | 「捉住了这个主要矛盾，一切问题就迎刃而解了」 |
| **结论产生于调查末尾** | 「一切结论产生于调查情况的末尾，而不是在它的先头」 |
| **乐观悲观同源** | 估得过高=机会主义，估得过低=盲动主义，都因没调查 |
| **内因决定胜负** | 「外因是变化的条件，内因是变化的根据」 |
| **同时打两种极端** | 「亡国论」与「速胜论」都「是主观的和片面的」 |
| **集中优势，各个歼灭** | 「平分兵力，处处攻击，处处不得力」是头号错误 |
| **党八股八条** | 八条文风病症 = 八种思维病症，可当写作自检清单 |

总纲是**实事求是**：

> **实事**（客观存在的一切事物）＋**是**（内部联系即规律性）＋**求**（我们去研究）

## 文件结构

```
SKILL.md              主文件：总纲 + 10 个核心模型 + 160 篇完整索引 + 主题索引
patterns.md           40 个思维方法模式（何时用 → 怎么做 → 取舍）
cheatsheet.md         速查卡：征兆诊断表、20 条决策规则、决策树、取舍矩阵、阈值、坏味道
glossary.md           核心术语定义（标注出处篇号）
chapters/             160 篇逐段拆解
  ch001-*.md ...      每篇含：核心主张 / 思维方法 / 关键概念 / 关键要点
meta.json             篇目元数据（篇号、标题、日期、卷次、字数）
```

按需加载：只读 `SKILL.md` 约 3千tokens；深入某章才加载该章文件。

## 使用提醒

- 原文是 **1937–1949 年的历史文献**。其中的政治判断与历史结论是**特定时代语境的产物**。本技能提炼的是**可迁移的思维工具**，不主张其具体结论在今天仍然成立。
- 毛泽东本人强调「具体问题具体分析」——用他的方法之前，先判断它是否适配你的处境。
