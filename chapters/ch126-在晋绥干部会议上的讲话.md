# 126｜在晋绥干部会议上的讲话

> **卷次**：第四卷 ｜ **成文**：一九四八年四月一日 ｜ **原文**：约 7,833 字

## 核心主张
**政策和策略是党的生命，统一战线是策略的总枢纽。** 晋绥一年土改整党之所以成功，不是因为群众天然拥护，而是因为同时做了两件相反的事：**发动群众斗争（反右）** 与 **纠正运动中的「左」偏向（防左）**。土地改革必须「依靠贫农、团结中农，有步骤地、有分别地消灭封建剥削制度」——打击面有硬性上限（户数不超过 8%、人数不超过 10%），且「消灭封建剥削制度」而非「消灭地主个人」。党与群众的关系被定义为双向的：**正确的意见党领导群众实现，不正确的意见党教育群众改正**。

## 思维方法

### 1. ⭐⭐ 用「两条同时进行的曲线」评估一场运动
- **结构**：任何群众运动都有两条风险曲线——**不发动群众**（右，干部包办、运动不起来）与**发动过度**（左，打击面失控、误伤自己人）。
- **判据**：工作成功与否**必须从两方面看**。晋绥的成功＝「反对了右的偏向，发动了群众斗争」＋「纠正了在运动中发生的几个『左』的偏向，因而使全部工作走上了健全发展的轨道」。
- **迁移**：任何变革型项目（组织整顿、产品改版、团队重组）都要同时问两件事：动力够不够？边界清了没有？只答其一即为半成品。

### 2. ⭐⭐⭐ 政策是「生死线」，不是「可选项」
- **原文信号**：「政策和策略是党的生命」（本篇核心命题）。策略错了，「我们就会左右摇摆，就会贻误我们的工作」。
- **方法论含义**：**执行层不能自行发明政策**。政策的权威性来自它的正确性，而正确性只能由效果检验——所以要**先试点、留反馈通道、错了立刻改**。
- **可操作**：把政策制定与政策执行分成两个角色，**执行者只负责「按情况落实 + 反馈偏差」，不负责「改政策」**。

### 3. ⭐⭐ 「从群众中来」的具体化：党与群众的双向关系
- **原文**：「凡属人民群众的正确的意见，党必须依据情况，领导群众，加以实现；而对于人民群众中发生的不正确的意见，则必须教育群众，加以改正。」
- **反面教材**：地委书记会议只强调了前半句，笼统提出「群众要怎样办就怎样办」的口号，**助长了尾巴主义错误**。
- **方法论**：**「群众要怎样办就怎样办」是错误的**——它是把「群众」当成一个无差别的整体。真实操作必须**先对群众意见分类**：哪部分是方向正确的（提炼为政策）、哪部分是情绪化/局部化的（引导修正）。不做这个分类，就会滑向民粹或官僚。

### 4. ⭐⭐ 定量约束政策边界：打击面有硬上限
- **数字**：土地改革「总的打击面，根据中国农村封建剥削制度的实际情况，一般地不能超过农村**户数百分之八左右，人数百分之十左右**」；老区和半老区「此项数目还要减少」；团结对象是「户数百分之九十二左右，人数百分之九十左右」的全体农村劳动人民。
- **推论**：**政策不是靠说服力约束的，是靠数字约束的**。给一个模糊的指示留出模糊的执行空间，等于给错误留出空间。
- **做法**：任何政策设计都要给出**可核查的量化边界**（占比上限、下限、例外条件），而不是靠「注意不要……」来约束。

### 5. ⭐⭐ 分地区、分阶段：把「统一战线」变成时间函数
- **分地区**：在**能巩固地占领**的区域集中力量做彻底改革；在**暂时尚难巩固**的区域「不要忙于进行土地改革」，只做「按照当前情况有利于群众的工作」，**以待情况的变化**。
- **分阶段**：刚解放的区域，第一阶段只「提出和实行中立富农和中立中小地主的策略，将打击面缩小到只消灭国民党的反动武装和打击豪绅恶霸分子」；等「群众的觉悟程度和组织程度被提高了」，再「逐步地发展到消灭全部封建制度的阶段」。
- **关键约束**：「在新区，分浮财和分土地，均必须在环境比较安定和绝大多数群众充分发动之后，否则就是冒险的，靠不住的，有害无益的。」
- **方法论**：**变革的深度必须匹配环境的稳定度和群众的基础成熟度**。顺序错了（先动利益、后做发动），就是把不确定条件下的动作当成了确定条件下的动作。

### 6. ⭐⭐ 「有分别地消灭」：普遍原则 + 差别待遇
- **做法**：在「平分土地、消灭封建制度的大原则下面，不是一律地而是**有所分别地**决定和实行给予这些不同情况的人们以**不同的待遇**」——分别地主和富农，分别大中小，分别恶霸与非恶霸。
- **配套原则**：**消灭的是剥削制度，不是被剥削者个人**。「对地主必须分给和农民同样的土地财产，并使他们学会劳动生产」——**给退出者一条活路，才能零对抗地完成退出**。
- **推论**：**「一律」是执行者最容易偷懒的选择**——因为它免去了分类判断的责任。政策一旦规定「一律」，分类工作就消失了，而分类正是政策落地最难也最有价值的部分。

### 7. ⭐⭐ 「有步骤」：反对一次性到位
- **原文**：「必须依据环境所许可的情况，农民群众的觉悟程度和组织程度，决定发动斗争的策略，**不要企图在一个早上消灭全部的封建剥削制度**。」
- **方法论**：把「彻底」重新定义为**方向上的彻底**（目标不动摇）＋ **节奏上的渐进**（分阶段实现）。误把彻底理解成「一次做完」，会导致「企图在一个早上」推进而失控。

### 8. ⭐⭐ 政策的直接目的必须是经济生产，而不是道德姿态
- **原文**：「发展农业生产，是土地改革的直接目的。」「只有消灭封建制度，才能取得发展农业生产的条件。」
- **推论**：**一项政策若不能提高生产率，它就是零和的资源再分配**。土改之后必须「立即提出恢复和发展农业生产的任务」。
- **附带的资源纪律**：土改中要「尽一切努力最大限度地保存一切可用的生产资料和生活资料」，反对「破坏和浪费」「大吃大喝」，注意节约。**破坏性革命的隐含成本必须被明确计入**。

### 9. ⭐⭐ 整党方法：邀党外积极分子参加支部会议
- **做法**（晋察冀平山县经验）：「邀集党外群众中的积极分子参加党的支部会议，展开批评和自我批评」，目的是「改变党的组织的成分不纯或者作风不纯的现象，使党和人民群众密切地联系起来」。
- **机制**：**把评价权交给被服务的人**，而不是交给上级或内部。这是「从群众中来」在组织层面的落地形态。
- **配套**：「对于那些犯了错误但是还可以教育的、同那些不可救药的分子有区别的党员和干部，**都应当加以教育，而不是抛弃他们**」——**划出可教育与不可救药的分界**，避免运动扩大化。

### 10. ⭐ 民主政权的组织形式：贫农团 → 农会 → 人民代表会议
- **三级演进**：土改前段靠**贫农团、农会**；在「贫农团和农会的基础上」建立**区村（乡）两级人民代表会议**；「在区村两级人民代表会议普遍地建立起来的时候，就可以建立县一级的」。
- **权力归属**：「一切应有的权力必须归于代表会议及其选出的政府委员会」，此后贫农团和农会降为助手。
- **关键限定**：「只有基于**真正广大群众的意志**建立起来的人民代表会议，才是真正的人民代表会议」，且要「自然地而不是勉强地」实现联合——「当然不是勉强凑数」。
- **方法论**：**权力应当随群众组织的成熟度逐级上移**，而不是一次设计到位。判断标准是「群众基础够不够」，不是「架构是否先进」。

### 11. ⭐ 领导方法的成败归因：先查领导的错，再查执行
- **原文归因**：晋绥地委书记会议「批判了过去工作中存在着的右的偏向」，且会自身「没有按照老区半老区和新区的不同的情况决定不同的工作方针」；抗日时期的缺点「主要地是未能依靠最广大的群众克服党内和政府内在某种程度上的成分不纯」，原因之一是「**缺乏对于党和群众的许多真实情况的了解**」。
- **方法论**：**当一个系统出问题，先假设它的设计者信息不足或判断有误，再假设执行者不努力**。本篇把失败归到「不了解真实情况」，即回到「实事求是」的方法论总纲。

### 12. ⭐ 政策传达要防「记具体、忘总纲」
- **原文**：「许多同志往往记住了我党的具体的各别的工作路线和政策，**忘记了我党的总路线和总政策**。」
- **后果**：「真正忘记了我党的总路线和总政策，我们就将是一个**盲目的不完全的不清醒的革命者**……就会**迷失方向，就会左右摇摆**。」
- **解法**：文末连说两遍总路线——**总路线 + 具体路线要成对记忆**。这是「防止局部最优破坏全局」的认识论手段。

## 关键概念
- **政策和策略是党的生命**：政策与策略决定方向，方向错则执行必错（126）。
- **总路线与总政策**：无产阶级领导的、人民大众的、反帝反封建反官僚资本主义的革命；土地改革总路线是依靠贫农、团结中农、有步骤有分别地消灭封建剥削制度、发展农业生产（126）。
- **打击面 / 团结面**：打击面 ≤ 户 8%、人数 10%（老半老区更少）；团结面为 92% 户、90% 人的全体农村劳动人民（126）。
- **有步骤、有分别**：方向彻底、节奏渐进、待遇差别——三层含义同时成立（126）。
- **分地区、分阶段**：把环境稳定性与群众成熟度作为改革深度的函数（126）。
- **尾巴主义**：把「群众要怎样办就怎样办」当政策，放弃党的领导与教育职能（126）。
- **成分不纯 / 作风不纯**：党内两种病——组织成分被坏人混入，或干部官僚主义仗势欺人（126）。

## 心智模型
- **变革的双曲线**：不动 = 右，过头 = 左；成功 = 双线同时达标。
- **政策的边界要用数字写，不用形容词写**：「不超过 8%」比「尽量少」有效得多。
- **政策制定 ≠ 政策执行**：执行者只落实和反馈，不改政策。
- **退出的经济学**：把退出者安排成新的生产者，对抗成本趋近于零。
- **彻底 ≠ 一次做完**：彻底是方向，渐进是节奏，两者不可互换。
- **变革深度 = f(环境稳定性, 群众成熟度)**：脱离这个函数就是冒险。
- **先查设计者的信息，再查执行者的态度**。
- **变革的隐含成本（生产资料破坏、报复杀人）必须显式计入**。

## 反模式
- **「群众要怎样办就怎样办」**：取消分类与领导，助长尾巴主义。
- **一律化**：不分地主富农、大中小、恶霸与否——省掉分类责任，执行必走样。
- **扩大打击面**：把无剥削或轻微剥削的劳动人民错划进打击圈，破坏统一战线基础。
- **一个早上消灭全部**：忽视群众觉悟与组织程度，冒险推进。
- **侵犯工商业**：打击了本应保护的工商业对象，破坏经济恢复基础。
- **乱打乱杀 / 使用肉刑**：把惩办极少数罪大恶极者扩大为普遍惩罚，授人以报复机会。
- **绝对平均主义**：破坏工商业、倒退的反动落后思想，与赞助农民平分土地是两回事。
- **官僚主义分子把持的经济组织**：变工队与合作社被把持则垮台，「毫不可惜」——但被群众拥护的要「细心保存和发展」。
- **骄傲自满**：「决不可以因为成功，因为受到奖励，而骄傲自满」。
- **记具体政策、忘总路线**：局部正确、全局迷失方向。

## 关键要点
1. 政策的地位：「政策和策略是党的生命」；总路线与具体政策必须成对掌握，否则「左右摇摆」。
2. 双重评估：同时检查是否发动了群众（反右）与是否纠正了偏向（防左）。
3. 党群关系是双向的：正确的意见领导实现，不正确的意见教育改正——「群众要怎样办就怎样办」是错误的。
4. 定量边界：打击面 ≤ 户 8%、人数 10%；团结面 ≥ 户 92%、人数 90%。
5. 分地区分阶段：能巩固的区域重做，尚难巩固的区域只做有利群众的事「以待情况的变化」。
6. 三步落地：分浮财分土地必须在环境安定 + 群众充分发动之后，否则是「冒险的、靠不住的」。
7. 消灭制度不消灭个人：地主同样分地、同样劳动；只惩办「罪大恶极」者，禁止乱打乱杀与肉刑。
8. 整党靠外部评价权：邀党外积极分子进支部会议展开批评与自我批评；可教育者教育、不抛弃。
9. 权力随成熟度上移：贫农团/农会 → 区村人民代表会议 → 县一级；一切权力归代表会议及其选出的政府委员会。
10. 土改的直接目的是发展农业生产；「消灭封建制度、发展农业生产」是变农业国为工业国的「最后目的」。
11. 领导方法归因：先查领导是否掌握真实情况（设计者信息不足），而非先指责下级不努力。
