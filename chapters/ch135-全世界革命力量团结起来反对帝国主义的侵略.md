# 135｜全世界革命力量团结起来，反对帝国主义的侵略

> **卷次**：第四卷 ｜ **成文**：一九四八年十一月 ｜ **原文**：约 2,368 字

## 核心主张
十月革命把民族问题从「欧洲反民族压迫的局部问题」扩大为「各被压迫民族、各殖民地及半殖民地从帝国主义之下解放出来的总问题」，并在社会主义的西方与被奴役的东方之间架起一道桥梁。因此战胜法西斯与今日反对美国侵略，都必须以苏联为首团结起全世界的革命力量。

## 思维方法

### 1. ⭐⭐ 用「一个事件改变问题尺度」作为全文杠杆
- 引斯大林的判断：十月革命「**扩大了民族问题的范围**，把它从欧洲反对民族压迫的斗争的**局部问题**，变为各被压迫民族、各殖民地及半殖民地从帝国主义之下解放出来的**总问题**」。
- 三个后果被拆开讲：①**扩大了范围**；②「开辟了广大的**可能性和现实的道路**」；③「从而在社会主义的西方和被奴役的东方之间**架起了一道桥梁**……建立了一条从西方无产者经过俄国革命到东方被压迫民族的新的反对世界帝国主义的革命战线」。
- **可迁移**：判断一件工具/事件的价值时，看它是否**改变了一个问题的尺度**（局部 → 全局）。尺度变了，旧方法全部失效。

### 2. ⭐ 「两个必要条件 + 一个充分条件」式的组织论证
- 「既要革命，就要有一个革命党。」→ 条件一：**要有按马克思列宁主义的革命理论和革命风格建立起来的革命党**。
- 「**每一个国家内部的一切革命力量必须团结起来，一切国家的革命力量必须团结起来**，必须组成以苏联为首的反对帝国主义的统一战线」→ 条件二：**内外两个层次的团结都不可省**。
- 「否则就不能胜利」→ 两条件为**必要条件**；「这个敌人的基础是虚弱的……因此，它是能够被战胜的」→ 构成**可行性**判断。
- **可迁移**：组织论证要分清「必要条件」与「可行性判断」两层，不要把「只要有 X 就能成」写成单链条。

### 3. ⭐⭐ 对敌方力量同时给两个相反方向的警告
- 「这个敌人**还是有力量的**」，因此必须团结。
- 但「这个敌人的基础是**虚弱的**，它的**内部分崩离析**，它**脱离人民**，它有**无法解脱的经济危机**」，因此它是能够被战胜的。
- 两个警告合并成一句：「**对于敌人力量的过高估计和对于革命力量的估计不足，将是一个极大的错误。**」
- **可迁移**：判断敌我强弱时，要**同时禁止两个方向的误差**（轻敌与长他人志气），并用一条对偶句把两个方向钉在一起，作为团队共识的锚。

### 4. ⭐ 用历史事件作为「前提已成立」的证明
- 「以苏联为首的世界革命统一战线，**战胜了法西斯主义的德意日**……假如没有十月革命，假如没有苏联共产党，没有苏联，没有苏联领导的西方和东方的反对帝国主义的革命统一战线，**还能设想战胜法西斯德意日及其走狗们吗？**」
- 由此建立一条类比推理：十月革命为解放事业开辟道路 → 二战的胜利「**就是给全世界工人阶级和被压迫民族的解放事业开辟了更加广大的可能性和更加现实的道路**」；并附警告：「对于第二次世界大战的胜利的意义**估计不足，将是一个极大的错误**」。
- **可迁移**：抽象论断要挂在一个已发生的成功案例上。用「假如没有 X 还能想象 Y 吗」的反问句式，可以在最短篇幅内证明某要素的必要性。

### 5. ⭐ 「孤立状态被终结」被单列为一个转折点
- 「一向孤立的中国革命斗争，自从十月革命胜利以后，**就不再感觉孤立了**。我们有**全世界的共产党和工人阶级的援助**。」
- 并把孙中山的行动作为同一判断的旁证：「中国革命的先行者孙中山先生是理解的，他确定了联合苏联反对帝国主义的政策。」
- **可迁移**：评估一个外部事件对自身的作用时，专门检查一项：**我方是否从「孤立」状态变成了「有外援」状态**。这一条比抽象的资源增加更具决定性。

### 6. 理论自信与困难并存
- 「我们知道，我们面前还有许多困难。但是，我们不怕这些困难。我们认为困难是必须克服，**并且能够克服的**。」
- **可迁移**：信念表达要带上「承认困难 + 给出克服理由」的两段式，否则会被读成空话。

## 关键概念
- **民族问题范围的扩大**（ch135）：十月革命把反民族压迫从欧洲局部问题变为全世界被压迫民族的总问题。
- **革命战线／桥梁**（ch135）：在社会主义西方与被奴役东方之间架起的反对世界帝国主义的统一战线。
- **两个必要条件**（ch135）：一个按革命理论建立的党 + 内外两个层次的革命力量团结。
- **敌人的虚弱基础**（ch135）：内部分崩离析、脱离人民、无法解脱的经济危机。
- **两个相反方向的估计错误**（ch135）：过高估计敌人力量与过低估计革命力量，同样都是极大错误。

## 关键要点
1. 判断一件事物的价值，看它是否**改变了一个问题的尺度**（局部 → 全局）。
2. 组织论证分两层写：必要条件（缺一不可）与可行性判断（能不能赢）。
3. 判断敌我强弱时同时禁止两个方向的误差，并用一句对偶句把两者钉成共识。
4. 抽象论断挂在一个已发生的成功案例上，用「假如没有 X 还能想象 Y 吗」证明某要素的必要性。
5. 每次评估外部事件，专门检查一项：自身是否从「孤立」转为「有外援」。
6. 信念表达用「承认困难 + 给出克服理由」两段式，避免被读为空话。
