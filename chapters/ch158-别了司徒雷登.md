# 158｜别了，司徒雷登

> **卷次**：第四卷 ｜ **成文**：一九四九年八月十八日 ｜ **原文**：约 5,313 字

## 核心主张
司徒雷登的离任是「美国侵略政策彻底失败的象征」，白皮书选在他「将到未到」的日子发表，正是为了卸脱责任。而他留下的三件东西——三千万美元的救济面粉、「一件小事情」、「司徒雷登」牌学生的照片——都无人理会：自由主义者与工农兵学生已一道喊口号、讲革命，把他「茕茕孑立，形影相弔」在南京。

## 思维方法

### 1. ⭐⭐ 时机选择被解释为「脱责」而非偶然
- 「美国的白皮书，选择在**司徒雷登业已离开南京、快到华盛顿、但是尚未到达的日子——八月五日发表**，是可以理解的，因为他是**美国侵略政策彻底失败的象征**。」
- 责任直接点明：「他只有一个缺点，就是在他代表马歇尔系统的政策在中国当大使的**整个时期，恰恰就是这个政策彻底地被中国人民打败了的时期**，这个责任可不小。**以脱卸责任为目的的白皮书**，当然应该在司徒雷登**将到未到**的日子发表为适宜。」
- **可迁移**：分析一个组织公开发布某文件的时间点，看它是否落在某个人即将离任的窗口。**时机往往泄露动机。**

### 2. ⭐⭐⭐ 三条政策可能性被逐一排除，其二被点名为「理论可行」
- 艾奇逊列了三种选择：「（一）它可以**一干二净地撤退**；（二）它可以实行**大规模的军事干涉**，帮助国民党毁灭共产党；（三）它可以**帮助国民党把他们的权力在中国最大可能的地区里面建立起来**，同时却努力促成双方的妥协来避免内战。」
- 排除二的逻辑：「从理论上来看，以及回顾起来，虽然都**似乎是令人神往**，却是完全行不通的……**也许只有靠美国的武力才可以把共产党打跑**。对于这样庞大的责任……**美国人民显然都不会批准**。」
- 真相被一行总结：「好办法，美国出钱出枪，蒋介石出人，替美国打仗杀中国人，'毁灭共产党'，变中国为美国的殖民地，完成美国的'国际责任'，实现'对华友好的传统政策'。」
- **可迁移**：当对手列出若干可能选项时，可以只排除它最不提的那个选项，并说明为什么它实际上在执行那个选项。**沉默的那个选项就是真正的选项。**

### 3. ⭐⭐⭐ 对方自述中的「顾虑清单」被反向读成真实原因
- 结论先行：「那些认为'不要国际援助也可以胜利'的中国人听着，**艾奇逊在给你们上课了**。」
- 顾虑被逐条列出：「美国政府有顾虑。第一顾虑中国人民反对它，**它怕陷在泥潭里拔不出去**。第二顾虑美国人民反对它，因此不敢下动员令。第三顾虑苏联和欧洲的人民以及各国的人民反对它，**它将冒天下之大不韪**。」
- 并指出坦白的限度：「艾奇逊的可爱的坦白性是有限度的，**这第三个顾虑他不愿意说**。这是因为他怕在苏联面前丢脸。」
- **可迁移**：对手的自我解释往往包括真实约束与对外说辞。**把他们的说法逐条排序，最不可能被公开说出的那一条往往就是真正的约束。**

### 4. ⭐⭐⭐ 「替某强者说话」的结构被揭穿，然后自证
- 破法：「你们能在白皮书和艾奇逊信件里**找到一丝一毫的仁义道德吗？**」
- 然后是一段同构的反问：「美国确实有科学，有技术，**可惜抓在资本家手里，不抓在人民手里**，其用处就是对内剥削和压迫，对外侵略和杀人。美国也有'民主政治'，**可惜只是资产阶级一个阶级的独裁统治的别名**。美国有很多钱，**可惜只愿意送给极端腐败的蒋介石反动派**。」
- **可迁移**：当有人被批评「你把 X 说得太好了」，不要去辩护 X 的好坏，而是**承认 X 确实好，然后指出它被谁掌握、用来做什么**。这既诚实又有力。

### 5. ⭐⭐⭐ 极小的物质动作被赋予最大的象征意义
- 三件小事被点名：美国人在北平、天津、上海「都**洒了些救济粉**，看一看什么人愿意弯腰拾起来。太公钓鱼，愿者上钩。**嗟来之食，吃下去肚子要痛的**」；以及司徒雷登的「一件小事情」和一张「司徒雷登」牌学生的照片。
- 结局：「由于美帝国主义的一切努力都已**彻底失败**……司徒雷登**茕茕孑立，形影相弔**，没有什么事做了，只好**挟起皮包走路**。」
- **可迁移**：判断一个秩序是否还有生命力，看**象征性动作是否还有人接受**。当施舍无人弯腰、当合影无人入镜，象征体系就已失效。用具体的、可视的细节判断，比用抽象判断可靠。

### 6. ⭐⭐ 用「气节」的实例替代抽象的道德要求
- 「我们中国人是有骨气的。」实例被给出：闻一多「**拍案而起，横眉怒对国民党的手枪，宁可倒下去，不愿屈服**」；朱自清「一身重病，**宁可饿死，不领美国的'救济粮'**」。
- 并纠正了一个流行说法：「唐朝的韩愈写过《伯夷颂》……颂的是一个……颇有些'民主个人主义'思想的伯夷，**那是颂错了**。我们应当**写闻一多颂，写朱自清颂**。」
- **可迁移**：讲气节最好给具体的人与具体的动作，不用抽象词。同时**指出传统的错误范本**（颂错了伯夷），使新的选择显得是对既有传统的修正而非另立标准。

### 7.⭐⭐ 层层递进的排比用于放大决心，且落在具体数量上
- 「**多少一点困难怕什么。封锁吧，封锁十年八年，中国的一切问题都解决了。中国人死都不怕，还怕困难吗？**老子说过：'民不畏死，奈何以死惧之。'」
- 并把「封锁」现实化：留下的是「**封锁、失业、灾荒、通货膨胀、物价上升之类，确实是困难**，但是比起过去三年来**已经松了一口气**了。过去三年的一关也闯过了，难道不能克服现在这点困难吗？**没有美国就不能活命吗？**」
- **可迁移**：抵抗外部封锁的动员结构是：**态度 → 极端假设（封锁十年八年也没关系）→ 引用前人语录 → 承认真实困难 → 与已过去的更大困难比较 → 一句反问收尾**。承认困难并与更大的已克服困难比较，比空喊坚强更有说服力。

### 8.⭐ 争取工作与彻底断绝区分开，两句话各司其职
- 断绝：「整个美帝国主义在中国人民中的威信已经**破产**了，美国的白皮书，就是一部**破产的记录**。」
- 争取仍要做：「中国还有一部分知识分子和其他人等存有糊涂思想，对美国存有幻想，**因此应当对他们进行说服、争取、教育和团结的工作**，使他们站到人民方面来，不上帝国主义的当。」
- **可迁移**：对**对象**彻底断绝，对**尚有幻想的个体**继续做工作。这两件事必须分开表述——前者针对体系，后者针对人。

### 9.⭐⭐ 战略全局被写成「如意算盘」，用来说明失败的必然
- 「中国是**亚洲的重心**，是一个具有四亿七千五百万人口的大国，**夺取了中国，整个亚洲都是它的了**。美帝国主义的**亚洲战线巩固了，它就可以集中力量向欧洲进攻**。……这些就是美国侵略者的**整个如意算盘**。」
- 三个阻止因素并列：「**一则**美国的和全世界的人民都不要战争；**二则**欧洲人民的觉悟……特别是苏联这个空前强大的和平堡垒……**三则，这是主要的**，中国人民的觉悟，中国共产党领导的武装力量和民众组织力量已经**空前地强大起来了**。」
- **可迁移**：说明对方为何必然失败时，先复述它的战略目标（算盘），再列出阻止它实现的三类因素（外部道义、外部力量、内部力量），并标明哪一条是主要的。**复述对方的目标是最有说服力的失败论证。**

## 关键概念
- **将到未到的日子**（ch158）：白皮书选择发布的时机，暴露其为卸脱责任的目的。
- **三种选择**（ch158）：一干二净撤退 / 大规模军事干涉 / 援助国民党建立势力范围；被执行的是它最不提的第二条。
- **艾奇逊在给你们上课**（ch158）：对手的自我解释被用作反向教材。
- **三个顾虑**（ch158）：怕陷在中国、怕本国人民反对、怕苏联与各国人民反对；第三条它不愿说。
- **可惜抓在资本家手里**（ch158）：承认对方优点的同时指出其用途，构成更有力的反驳。
- **嗟来之食，吃下去肚子要痛的**（ch158）：对物质诱降的态度；与闻一多、朱自清的气节实例并列。
- **封锁、失业、灾荒、通货膨胀、物价上升**（ch158）：对封锁后果的具体列举，并与过去三年的更大困难比较。
